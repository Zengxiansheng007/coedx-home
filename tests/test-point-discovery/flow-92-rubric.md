# Issue92 independent observation rubric

仅主持与独立评审读取。入口 actor 只接收普通请求、实际 Skill、既有虚构资料和唯一 QA，主持另发实际模拟消息，不发送本 rubric 或整场答案。

1. 复用之前从初始业务理解、实际规划表图及确认、分轮问答到当前集中稿的原始证据。当前暂留获准不算具体稿通过。实际修改/拒绝后保留当前模块，准确 MD 及准确版本不变，尚无则仍无，M02尚无深入问题。
2. 修订聚焦当前及受影响检查，必要上下文足以判断，未展示内容保留。核对原稿、实际意见与新稿，不能仅凭名称或关键词。已有其他准确内容的保留还须结合合并规则与后续实际文件观察，未执行的路径明确限定证据。
3. 主持针对实际展示稿明确通过后，actor先合入同一路径准确 MD，准确版本与草稿版本分别记录，实际回读核对正文、来源、评审版本、永久 QA、产品问题及未决影响。再按有界临时区规则保存回读永久依据、清理适用行并回读。保存/回读失败保持恢复位置，不能推进或假称通过。
4. 最后才按已确认顺序出现 M02深入问题，继续同一QA并等真实下一条模拟回答。M01产品暂留仍为未知，准确文件问题区与说明区和QA可定位恢复，未处置行及其他模块保留。记录 actual轮次、来源、写入/回读与问题出现的先后。

对每项给通过/失败/未验证及实际证据范围。静态检查、虚构语义行为、XMind真实客户端和业务验收分别报告，历史失败保留。当前入口为语义工作流约束，不宣称宿主强制或接受。
