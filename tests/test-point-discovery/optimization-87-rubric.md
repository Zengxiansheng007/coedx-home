# #87 独立语义评审

执行者仅接收普通请求、资料、源码入口与获授权输出目录，主持按实际提问分轮发送答复。本 rubric 留给主持与独立评审，不把预设答案交入口 actor。资料内明确答案直接保留，不以隐藏答案制造失败。

## 实际观察

- 对真实部分答复、漏答、新条件、事实缺口及依赖逐轮核对。来源和未问主题均有去向。过程 MD 同时承载临时覆盖区和永久问答，问题/分支/准确文档身份清楚，无 JSON 业务状态副本。
- 暂停后真实回读同份过程记录及准确 MD，从实际未决处恢复，已明确且依据未变的决定直接复用。汇总前回查原始资料与答复历史。frontier为空、点数多或部分具体评审均不能代替覆盖处理。
- 主持仅批准已实际展示的明确范围时，准确文件只合入该范围，未处置漏答、待查快照和依赖继续保留。明确后问产品才形成完整产品事项，规则答复不替代具体评审。
- 当前范围覆盖复核、具体评审、同一路径准确 MD 更新后，实际将永久问答/答复历史、资料决定、产品问题/影响、具体稿与准确 MD 实际路径/版本及评审依据保存并回读，再只清理已收尾临时行并回读。观察真实文件变化及先后顺序，不能仅凭文件名、表格或 B/Q 字样判通过。
- 清理后永久内容完整，产品未知仍可恢复，其他模块与未处置行留存，已收尾行实际移除。清理无需新增批准门，不归档第二份临时表。实际未做的清理报告未验证。
- 快照由主持实际写入或发送后才提供准确路径，执行者实际读取版本及 ID。事实与业务预期分别记录，未交付时没有断言已收录。只读模拟资料不代替真实业务执行。
- 后续模块引入影响 M1 的真实新条件时，执行者从永久依据限定重开，新的 B/Q 超过历史最大值且关联旧问题。未变取消、名称共用及用途差异等保留，受影响具体点按 #86 聚焦评审后更新原准确 MD。

## 结果与证据

保存每轮实际请求、答复、展示版本、文件身份和未决状态。按六项 ticket AC 分别给通过/失败/未验证及轮次/文件依据。保留 RED 原始行为和历史限定结果，共用表达、规则粒度、操作终点、局部回问、聚焦评审不回退。静态、入口模拟、读取器、真实客户端和业务各自报告。

## 唯一问答与直接对话复核

逐轮实际检查跨阶段/模块的问答路径保持唯一、正文直接显示完整问题且允许自由回答，未使用问题卡或平行问答台账。准确测试点 MD 身份单列。核对未发问依赖、漏答、部分回答与业务答案未知/处置未定的不同状态，产品暂留必须能定位明确决定。模拟答复由主持实际分别发送，保存先后变化，不能预填通过。

## 当前模块集中生成

新运行先按实际 Skill 的当前模块生成条件处理已登记问题，并回读原始来源、部分答复及相关依赖，找回初轮未登记的相关分支。明确规则先存依据，已有稿件保留原版本；仅一批答完、部分已答或暂无可问问题均不出新稿。明确延期、转产品或排除须有实际决定，未知结果保持未知。其他模块独立问题不阻塞当前模块。历史运行和旧稿保持原身份，不据此预填本轮结果。
