# Issue93 independent observation rubric

仅主持与独立评审读取。Actor只收到普通接续请求、实际Skill、已发生的虚构资料和同一QA。主持在READY后独立发送实际新事实，后续答案按真实问题发送，不将本判据或整场答案发给actor。

1. 从现稿或后续模块新事实定位受影响规则及直接依赖，回读当前准确路径/版本、来源与永久答复。沿用旧有效答案，只重开相关B/Q。无关检查、来源和具体评审状态仍有效，既有产品问题继续未知。实际新问题直接在对话出现并写同一QA。
2. 主持实际仅部分回答后，比较准确文件hash与候选文件清单/版本，均保持原身份和字节。剩余未知、事实和依赖仍跟进，不自动进产品区或出新版。明确部分可分析，不能绕过当前模块评审门槛进入未获准模块。
3. 主持另发明确暂留与其他实际答案后，核对暂留只是处置完成，业务答案仍未知。相关原始来源、新事实、部分答案及依赖的实际复核先于集中修订。候选仅展示完整受影响规则/真实联动及必要上下文，原准确文件仍保持。产品或聊天答案本身不算具体稿通过。
4. 主持对实际展示稿发拒绝/修改后保持准确版本。Actor按明确意见修订并重新展示，若有新未知须再次处理。另收实际具体通过后才合入原准确路径，递增准确版本并实际回读。比对未展示业务段、来源历史、原产品问题及有效评审保真，记录被新决定替代的准确范围。永久保存回读与适用临时清理分别记录。

逐项给实际证据、通过/失败/未验证及限制，不能用静态关键词或文件存在替代语义。候选、真实XMind客户端与真实业务验收分别报告。保留初次失败及全部历史材料。
