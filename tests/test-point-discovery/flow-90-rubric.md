# Independent dialogue and QA review

- AC1 从实际对话观察每题问题、选项、假设例子、推荐和理由，允许自定义回答。无问题卡。跨轮次/阶段/模块始终同一问答MD，准确MD单列，无平行问题账本。
- AC2 独立问题可同轮。前提依赖保存于同一记录，未获得实际前置答复时未抢问依赖题。前提明确后实际提出适用的依赖问题。
- AC3 漏答保留实际未答，部分答复逐对象/条件/行为明确已知和剩余，不知道保留原话并实际询问处置，尚未明确暂留时产品区无此项。明确决定后才转产品并保留业务未知、影响与来源。
- AC4 至少两轮主持分别发送的真实模拟回答与actor后续输出。核对QA逐轮实际变化、来源/轮次、依赖、处置依据及回读记录。未发送回答为空，执行者未代扮主持。仅有关键词、存在文件或预写完整对话不算行为通过。
- 保留旧历史与冻结字节，新增runtime单独绑定。模拟、静态、XMind客户端及真实业务分别报告。本票不替代集中生成/整模块评审/跨模块重开的后续工单验收。
