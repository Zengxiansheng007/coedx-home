# #85 写作局部往返独立判据

仅主持方与评审者读取。演员读取普通请求、输入及实际Skill，主持方逐轮真实发送SIMULATION答复，保存问题、答复、展示版本和来源。不预填整场会话，不以关键词或文件存在判定通过。没有人为隐藏输入的要求，初轮编写已发现疑点时直接承接实际问题。

- 写作或自检中新发现的缺口实际回问，只暂停依赖未知的预期。现稿按原版本保留，已知部分按有效继续范围继续分析整理，相关问题处置并覆盖复核后集中修订，不把所有涉及同字段的内容冻结。
- 未问、漏答、部分未答及仅不知道保持其实际状态。明确暂留后才在模块顶部唯一产品区列完整问题、对象/条件、影响及受影响分支路径，实际暂留决定及其来源统一放在“资料与Agent交接说明”。正文短引用可回到该问题，未知预期没有被猜成确定结果或完整可执行检查。
- 后续明确答复只恢复其对象、条件、行为及直接依赖，保留原问题、原答复和暂留历史，未答继续处理，有效规则与排除不重复重问。
- 每份候选的结果可回溯原资料或实际答复。资料只明确新建保存、编辑取消时，不能据此认定编辑保存支持或保留原编号；遇到该疑点实际核对范围与规则，由主持方按真实问题答复，不提前补夹具答案。
- 明确部分继续及规则答复均不代替具体测试点评审、准确MD更新或交接选择。逐项记录实际产物定位、通过/失败/未验证，保留旧版已有通过行为与实际偏差，不把静态契约补充冒充行为修复证据。

只证明本样例模拟范围，真实业务、XMind客户端及下游执行分别按实际证据报告。
