# 八阶段入口开发模拟请求

主持只把以下实际请求交给fresh actor，actor读取目标Skill及请求资料。独立rubric由主持保留。所有材料均为虚构SIMULATION，逐轮答复由主持真实发送，记录实际文件及版本。

## 全新调用

SIMULATION。使用 $test-point-discovery 梳理借阅申请测试点。PRD v1说明普通读者可保存草稿、取消编辑、提交申请。保存产生草稿，取消不保留本次修改，提交变为待审核。本轮只看申请侧，不含审核处理。请先推进。

## 已有稿重新调用

主持取得实际形成的规划、同一问答MD与稿件后，在独立入口提供这些真实文件及可读来源，发送“SIMULATION。重新使用 $test-point-discovery，结合这些已有材料继续整理本轮测试点”。仅给出实际存在且内容足够的资料，不能在请求里补造规划确认或具体评审。

主持观察actor实际接续询问后，分别使用独立会话发送不答复、实际同意和拒绝接续的消息。无回复只记录待决定状态，不模拟沉默同意。

## 指定阶段和普通回答

在有实际部分答复的会话发送“SIMULATION。从阶段6继续”。随后针对actor实际原题给自由回答，检查原问题和同一问答MD的承接。另在具备准确稿时明确指定阶段8，实际等待交接范围决定。

入口行为、图像、解析、XMind客户端及真实业务分证。本请求不提供预填通过结果。
