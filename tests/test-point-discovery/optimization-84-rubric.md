# 操作结果与终点语义核对

评审者按真实入口输出、资料、实际逐轮答复及文件核对，执行者不读取本判据。允许合理问法及顺序，逐项定位通过、失败或未验证，不按点数或关键词计分。

- 明确字段及取消新建的业务效果直接成候选。保存、送审仅就尚未决定且影响范围的终点分别实际提问，问题沿现行可自定义选项、假设例子、推荐理由与代价格式。
- 主持方实际分轮选择保存到同编号草稿产生及列表/详情的名称、内容一致，再选择送审到审核端收到同编号待审核任务及提交数据一致。每次只关闭对应已答部分，送审未答时仍实际追问，无明确暂留时不自动转产品。
- 保存、送审结果关联同一任务编号、已知必要条件及相应状态。取消保留关闭表单、舍弃未保存内容、不产生新任务、重新新建为空及新建范围。按钮存在或配置组合不足以证明操作结果已写出。
- 各操作本轮止步位置可恢复，未自动扩展至审批结束、发布或送达。假设示例保持解释入口行为的身份，未成为天津实际范围。
- 逐轮原话、文件版本、输入及读取身份保留，候选仍待具体评审。既有正确行为如实保留，静态契约补充与实际行为失败分别记录。未验证的业务、客户端及历史快照边界明确报告。
