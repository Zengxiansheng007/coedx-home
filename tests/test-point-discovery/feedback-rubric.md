# #70 独立评审用标准

以70.md仍适用能力及#86优化核对本轮新输出，旧feedback-run保持历史证据身份。聊天和编辑MD中的业务变化核对来源版本、实际范围与含义后成为候选；前后准确文件版本证明业务检查未评审不写；局部遗漏保留；明确删除处理而歧义删除先问；完整核查跳转/接收关联影响，聚焦展示修改规则、适用范围、受影响差异/联动及必要上下文；M2原结论复用；未知局部澄清，仅产品回答没有批准检查；实际评审后按通过修改合入同路径并读回，省略的未改检查保留，说明区来源/决定/替代范围/原历史保留；局部未决由模拟用户决定继续，下一模块仍先澄清后编写评审。不修改下游。旧检查脚本只验证固定历史材料保真和时点，新行为语义需读本轮实际内容与原文。

纯技术定位/控件反馈按共同性质分流留给下游，记录其实际对象、来源与证据状态即可，原业务评审和交接范围继续有效。它不增加业务具体评审门，混合反馈仅将实际业务变化送回澄清和具体评审。
