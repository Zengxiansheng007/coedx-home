# Dialogue and single-QA natural-language request

执行者从实际 Skill 入口开始，只读指定的虚构资料、同一 QA.md 和逐轮实际主持消息。规划已确认的连续 actor 可从同一恢复位置接续。执行者不读 rubric，不预填模拟回复或通过结果。主持分别发送两轮以上模拟消息后观察每次对话与文件变化。使用新运行目录时保留历史运行，不修改旧冻结清单。

## 请求

请使用 skills/test-point-discovery/SKILL.md，接续主持指定的虚构资料及已有 QA.md，沿用已确认的模块和顺序，开始当前模块澄清。请把问题直接展示在对话，允许我自由回答。我会逐轮发送模拟回答。已有 QA.md 是本次所有阶段和模块的同一问答记录，当前仅澄清并等待我回答。在主持授权的目录保存过程，不调用外部模型、业务系统或下游。

## 主持操作

先取得实际问题再回应，可部分回答并保留独立题未答，后轮可说明某问题不知道。让actor实际追问处置，再单独作出明确暂留或继续查证决定。依赖问题在前提明确后才获得答复，不提前提供完整业务结局。若题目不同，按实际业务含义组织回答，不把未出现题号伪称已回答。至少两轮实际回复及其后续文件均保留，未走到的路径明确未验证。
