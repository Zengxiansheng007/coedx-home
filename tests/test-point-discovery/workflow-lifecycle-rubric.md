# #72 行为审查

对原始自然语言输入与实际逐轮输出核对，不能只核文件/关键词。

- 主动建议上下游，参与者、同一申请、传递方向/内容与未知影响明确；实际archify HTML/PNG且读图，表图一致，实际模拟答复决定范围。
- 整体先理解并实际澄清关系→模块表图确认→当前模块深入、承接流程衔接检查并写点/自检→评审，整体阶段无测试点稿，规划拒绝或等待不进模块；驳回重提保留未知，限定继续不消除未知，不增业务需求批准轮。
- 多角色仍流程优先，后续模块具体细化可观察；新事实回到同一问答 MD，仅重核受影响来源和真实依赖。部分回答保留现稿与准确版本，相关问题明确处置并复核后集中展示修改规则、适用环节、受影响差异/联动及必要上下文，省略的未改检查和原评审保留；业务答复不提前更新，具体重审后只合入通过修改并读回同一MD，未影响分支及历史决定保留。
- 生命周期具有实际状态、事件、条件、结果、生效和允许动作检查；未知时区/边界不造值，不自行加退回/撤回/重试。
- 保存、取消、送审等操作分别核对同对象业务结果与本轮终点。明确结果先存依据，当前模块处置及来源复核后集中形成候选，仅问未明且影响范围的终点。部分回答不覆盖其他操作，已知取消效果直接保留，送审接收结果及必要状态可恢复。后续审批或送达沿实际范围决定。
- 方法包括官方版本章节链接、适用/不适用、缺失信息、步骤、假设例及误用；不声称执行覆盖率。
- 所有答复标模拟并记录展示版本/实际文本/来源/范围/未决。过程结果不冒充真实业务、完整用例、XMind客户端验证或下游交接。
