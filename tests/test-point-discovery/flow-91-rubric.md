# Issue91 independent observation rubric

仅主持和独立评审读取。执行 actor 接收普通请求、原始资料和实际 Skill，可接续已真实产生的规划和同一问答记录。主持逐轮单独发送模拟消息，保存实际问答与文件变化。未实际发生的结果写未验证。

1. 多轮已知字段、漏答或部分回答只积累编写依据。题已答、一批完成或当前无可问问题均不能单独触发稿件。已知规则不重复索问。
2. 已登记问题有逐项依据或明确处置。事实查证和依赖有独立去向，空frontier不等于无阻塞。明确暂留不是业务已解决，继续分析不关闭未知。
3. 观察 actor 实际回读原始资料、部分答复和相关依赖，主动恢复初轮未登记的相关缺口。该缺口必须来自初始资料，不能只完成题数、用主持补新需求或假称已问。按实际追问和分别发送的答复核对处理后复核。
4. 明确延期、转产品或排除可构成处置，前提和范围可追溯。未知结果保持问题与影响，正文可短引用，禁止凭常识填期望。
5. 处理及复核完成后集中生成当前模块稿，其他独立模块未知保持原状态。共用规则只写一次、必要条件和计数/超限保留，规则级粒度和XMind MD说明区保真。仅待评审，无准确基线或下游执行主张。

报告给出每项实际轮次、来源和产物定位及通过/失败/未验证。关键词、文件存在和静态通过不证明行为。历史运行、冻结清单、客户端与真实业务边界分别保留。

MD结构同时核对标题后直接进入模块，模拟身份、评审范围、版本状态和暂留决定的来源/原话集中在“资料与Agent交接说明”。产品区保留完整问题、条件、影响和正文对应，正文短引用保持未知。发现偏差时保留原稿与真实观察，再经来源核对集中修订，不改写原始通过/失败证据。
