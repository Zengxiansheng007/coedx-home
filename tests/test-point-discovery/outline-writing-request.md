# 模拟资料 · 会议席位预约

请使用当前工作树的 test-point-discovery，按我指定的“会议席位预约 → 席位数量、通知方式、凭证格式”大纲编写待评审稿。这个模块已完成规划和阶段5的来源覆盖复核，以下是本轮确认的会议室预约规则和现有执行材料。在你获准的输出目录保存局部稿，给我评审。

- 单次最多预约 4 个席位，选择第 5 席时显示「单次最多预约 4 席」。
- 当联系地址省略或传空字符串时，“邮寄”在确认预约时提示“缺少地址”并且不生成信件。“自取”在确认预约时返回可打开的领取凭证。
- PDF、SVG 两种自取凭证均保留原版式和本次预约号。旧版桌面客户端曾在预览 SVG 时出现空白。手机端预览异常后的提示尚待现场取证，负责人在本次范围中明确同意暂留。

现有执行单 v2 的原编号如下。席位上限用 SEAT-01。联系地址省略的邮寄、自取分别用 ADDR-01、ADDR-02；传空字符串分别用 ADDR-03、ADDR-04。凭证 PDF 用 PASS-01，SVG 用 PASS-02。两例各用本格式的基准凭证，对照版式并核实预约号。
