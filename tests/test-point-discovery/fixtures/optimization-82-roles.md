# 购买模块资料 v1

SIMULATION。复用既有购买样例的价格与权益含义，以下内容作为独立虚构资料，不更新原roles-run。

R0 模拟规划接续前提。当前只整理购买模块，沿用模块到用户类型的组织，普通客户与有效VIP都在本轮。已决定只看有效会员状态下的单件新订单，排除到期、生效切换和旧订单处理，没有后续模块。

R1 普通客户单价100元，有效VIP单价80元。商品详情显示对应单价，单件结算和新订单金额使用该适用价格。无税费、运费或其他优惠。

R2 两类客户均只能查看本人订单。查看他人订单应被拒绝，会员等级不改变归属规则。现有页面观察只能证明显示内容，尚未执行操作测试。

R3 有效VIP可以专属预约。普通客户隐藏预约入口，并且预约操作应被拒绝。无管理员业务，VIP不拥有管理权。

R4 两类客户的订单归属业务规则已明确相同，资料没有规定底层实现是否复用。这里仅梳理测试点，不承诺任何业务执行结果。
