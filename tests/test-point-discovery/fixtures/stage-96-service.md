# 虚构服务申请 PRD v1

SIMULATION。用于本地开发，不来自真实项目。

申请人填写服务申请。保存会产生带唯一申请号的草稿，再次保存更新同一草稿。取消返回列表，丢弃本次未保存输入且保留已有草稿。标题必填，上限30字，中英文均计一字。

提交审核把该申请置为待审核。审核台接收什么对象、怎样与申请对应，本文尚未定义。审核员可同意或退回，同意后申请生效，退回后申请人可修改再提交。审核端是关联背景还是本轮完整检查范围，由使用者决定。

生效申请可发起资料同步，同步立即返回任务编号，稍后产生最终同步结果。编号与申请对应规则见后续接口资料，本轮不展开。

运营看板展示生效申请数，口径为当前生效且未撤销的申请。看板仅供观察，不修改申请。会员等级与费用计算本产品未定义，不据此增加范围。

本轮目标是先梳理申请维护，关联审核关系须先理解。同步与看板可建议后置。重复点击、网络异常、安全性能暂不纳入。
