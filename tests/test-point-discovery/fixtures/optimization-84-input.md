# SIMULATION — 云桥发布任务资料 v1

项目、资料与后续答复均为开发模拟，与天津业务无关。

## 已有模拟接续决定

模拟用户已确认本轮处理发布任务模块的新建表单，按字段与操作组织。表图规划已模拟确认，继续当前范围即可。可以先整理明确部分的编写依据，当前模块问题明确处置并来源覆盖复核后集中形成待评审测试点，尚未发生具体评审，没有准确 MD。

本轮涉及保存、取消和送审。保存和送审各需追踪到哪里尚未决定。后续问题由主持方逐轮回答。

## PRD v1，2026-11-07

P1. 新建表单有任务名称和发布内容，两者必填。任务名称最多20个字符，中文和英文字母均按一个字符计，超出后禁止保存和送审，提示“任务名称最多20个字符”。

P2. 首次保存为任务分配唯一任务编号。后续通过该编号对应同一任务，任务编号不可编辑。保存保留本次填写的名称和内容，任务支持草稿状态，列表及详情提供草稿查看。

P3. 取消新建会关闭表单、舍弃本次未保存的名称和内容，不产生新任务。重新进入新建表单时名称和内容为空。这里的取消不涉及已有任务。

P4. 草稿可送审。审核端按任务编号显示待审核任务及提交的名称和内容。审核端后续支持通过和驳回，通过后另有发布与渠道送达环节。

P5. 这次仅梳理已填好必填内容的普通草稿及新建取消。额外权限、并发、重试和定时发布不在本轮范围。
