# 采购支付追踪 PRD

模拟业务资料 v1，2026-11-07，不是真实产品规则。

## 申请与审批

申请人提交采购申请后进入待审批。申请具有唯一申请编号和金额。审批人批准或驳回同一申请；批准时确定批准金额，审批列表显示申请编号、决定和批准金额。

## 付款

付款列表沿用申请编号与批准金额。只有批准的申请才可能付款；关于是否还需要财务审核，产品尚未确定。已确认付款成功后会回写同一申请的付款状态。

## 看板

采购看板按申请编号关联付款结果，昨日已付款金额由付款成功记录汇总。“昨日”的时区和起止时刻未说明。看板图例点击隐藏对应系列，再点击恢复；图例只改变展示，不改变统计数据。
