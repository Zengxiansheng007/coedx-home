# 联系人导入 PRD，模拟资料 v0.1

P1：本模块接收联系人文件。每行含外部联系人编号、姓名、手机号；目标联系人保留这三个字段。外部联系人编号用于定位同一业务对象。一个文件包含多行，一个导入任务有单独的任务编号。

P2：文件提交后显示“已受理”和任务编号。任务页随后显示“处理中”，处理结束显示最终结果，可查看成功条数、失败条数及失败明细。失败明细能定位源文件行与外部联系人编号。

P3：系统会检查手机号及必填字段，检查未通过的行有失败原因。资料未写成功/部分成功/失败如何判定，也未写是否回滚正确行。

P4：暂未说明源文件重复编号和目标已有相同编号时怎样处理；也未描述重试、取消、超时及重复提交能力。
