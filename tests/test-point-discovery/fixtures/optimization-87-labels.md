# SIMULATION 标签小工具 PRD v0.1

全部资料及规划前提属于本地技术模拟。

## P1 范围与接续前提

已确定先 M1 标签维护，再 M2 标签筛选。流程与关联规划作为已确认接续前提，不重画图。允许先整理明确部分，进入下一模块按后续实际继续范围处理。排除批量导入、权限、删除及完整测试用例。

## P2 M1 标签维护

标签分工作、个人两类。新建名称都必填，中英文各计1，最多12字，超限拒绝保存并保留输入。工作标签还须填用途，个人没有此字段。

保存成功产生标签 ID，列表出现该 ID、已保存名称与类别，重新打开同一 ID 的详情显示相同内容。取消新建回到列表，不新增记录。终点到列表与详情。

## P3 M1 未明规则

同类重复、跨类同名、特殊符号及 emoji 计数、工作用途空值处理尚未决定，各项可分轮答复。

## P4 M2 标签筛选

按类别和名称筛选，结果展示匹配 ID、名称、类别。名称精确或包含匹配尚未决定。

数据来自本地索引快照，当前包未交付快照、生成版本或所含标签 ID，需资料提供方补交后实际核对。新建标签应可筛选的时点及索引更新条件也未决定。保存成功不提供收录事实。
