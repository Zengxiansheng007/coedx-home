# 设备统计资料 v1

SIMULATION。复用既有双图样例的筛选和计数含义，作为独立虚构资料，不更新旧two-chart-writing产物。

D0 模拟规划接续前提。设备统计模块的设备数柱图、告警数折线图均纳入，图表仍是组织主线。当前只整理下列已明确的筛选、计数与显示规则，不纳入刷新、导出、权限或性能。没有跨模块流程。

D1 两图都受站点、起止日期筛选。日期格式为日，含首尾日期，业务时区UTC+8。起止日期必须属于同一自然月，首日晚于末日时拒绝查询。这些是两图共同适用的规则。

D2 设备数按设备标识去重，同设备在所选日期多次上报只计1台。告警数按告警记录计，同设备有3条告警计3条。

D3 两图无数据都显示“暂无数据”。两图都支持图例隐藏后恢复对应系列，恢复保留筛选条件。没有两图交叉筛选或跳转。

D4 资料明确业务规则，但没有提供筛选器、查询代码或图例控件是否复用的实现证据。
