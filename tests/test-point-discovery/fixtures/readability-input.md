# 消息创建局部继续输入

本材料为开发验证用模拟资料，取自实际消息创建稿的同类规则并调整为可独立阅读的局部输入。下列范围和规则在本模拟内作为已有答复提供，真实业务以原项目资料为准。

本轮继续编写消息列表管理-创建消息。规划与当前范围澄清已经完成，编写范围仅包含下列群发方式、任务名称与定时配置，交具体测试点评审。当前没有准确基线。

## 群发推送方式

推送类型有极简推送和批量推送，均支持按个人用户定向，极简也允许多个个人用户。个人定向支持已知有效手机号和从数据库取得的有效 userid，添加后已选目标应与输入用户对应，不混入其他对象。

重复添加已经选中的个人用户提示“已添加”。不存在的个人账号提示并禁止加入。手机号与 userid 对应同一人时如何去重、数量上限与触达人数口径未知。输入方式还需分别覆盖无效号码、英文、特殊符号，这三类的格式规则与反馈未确认。

## 任务名称

任务名称为必填。完全相同名称跨推送维度、跨创建人均禁止重名。输入中文、英文、数字及混合内容时每个计1，页面显示20字符计数上限，超长是否拦截、前后空格和大小写归一规则未知。

## 推送时间管理

即时发送任务和定时推送任务分别为时间类型。定时只选未来时间，精确到秒。免打扰仅对定时生效，未来计划时间落入免打扰时段时延至对应结束时刻。

跨日时段22:00至次日08:00，计划时间为凌晨01:00时延至该日08:00。核对时间的时钟和阶段未知。恰好免打扰起止时刻已排除。当前仅梳理输入、配置与创建后的同任务回显，实际发送与送达不在本模拟范围。
