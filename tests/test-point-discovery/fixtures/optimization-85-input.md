# SIMULATION 收件组配置输入 v1

## 模拟 PRD

P1 收件组配置用于保存一份草稿，页面包含配置名称、可多选的收件组和已选人数。可选组包含其人员名单。已选人数显示选中组包含的人员人数。

P2 配置名称必填，按可见字符计数，最多20字符，超限阻止保存并提示限制。名称不要求唯一。没有选组时阻止保存并提示先选择收件组。

P3 成功保存产生一份草稿，列表中可按草稿编号找到同一份配置，重新打开显示保存的名称和选中组。保存后不发消息。

P4 取消编辑返回列表，原草稿保持进入编辑前内容。本轮保存检查止于同一草稿重新打开，取消止于返回后原草稿不变。

## 已有模拟决定

D1 本轮只做收件组配置模块，采用信息维护组织主线，包含名称、组选择、已选人数、保存及取消。规划范围与主线已确认，当前接续编写，无需重新绘图。

D2 人员数的变化属于当前范围。发送、审批、权限、性能及不同草稿同名检查已排除。资料明确规则先保存编写依据，发现依赖未知的部分先问，其他明确部分继续分析整理；当前模块相关问题明确处置并覆盖复核后集中出待评审稿。
