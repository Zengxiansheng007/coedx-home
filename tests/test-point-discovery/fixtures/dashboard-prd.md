# 模拟 PRD：服务运营看板

本资料仅用于 Skill 行为验收，不代表真实产品规则或用户确认。

## 看板范围

运营人员查看服务使用情况。首页包含概览卡片、访问趋势图、服务排行和访问明细；本期不做导出。首页上方可以选择日期区间和渠道（全部、移动端、网页端）。

## 概览卡片

展示访问次数与访问人数。访问次数按访问事件条数统计，访问人数按用户标识去重。卡片使用首页选择的日期和渠道。匿名用户如何识别尚未描述。

## 访问趋势

折线图按天展示访问次数。日期和渠道来自首页。需求写“数据及时更新”，未给出更新时限。没有数据时画什么尚未描述。

## 服务排行

展示所选日期内各服务的访问次数，按次数降序排列，显示前十名。渠道筛选是否作用于此图未写。并列次序未描述。

## 访问明细

点击服务排行中的某项进入该服务的访问明细，带入服务标识和当前日期区间。明细显示访问时间、服务名称、渠道；是否带入渠道条件未写。明细返回看板后的筛选保留行为未描述。
