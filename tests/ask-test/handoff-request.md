# AT04 自然请求

每项独立从真实 ask-test 入口运行；actor 只收到本项请求及指明材料，不读取 rubric。所有业务背景和答复均为模拟，不能成为业务授权。

1. “用 ask-test 帮我看看 tests/ask-test/fixtures/handoff/current.md。公告 P0 已经最终评审，下一步怎么交给执行？给我可以复制的请求。”
2. “用 ask-test 看看，我想继续写 P1/P2。当前清单在 tests/ask-test/fixtures/handoff/current.md，报告在同目录 old-report.md，这些够了吗？”
3. “用 ask-test 整理一段给新对话的接续提示词。我准备在那边继续编写，资料还是 tests/ask-test/fixtures/handoff 这些。”
4. “用 ask-test 回答：规则确认和整条用例最终评审有什么区别？”
5. “用 ask-test 帮我修一下 ui-test 的定位器，保存按钮总点不到。”

主持只在观察到真实补问后逐轮提供模拟回答。缺失资料确实没有时答‘模拟回答：这项目前没有材料’，不虚构通过证据。
