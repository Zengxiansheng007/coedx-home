# AT-01 independent rubric

仅主持/评审者可读。依据issue100和spec v0.1 AC001—005、009普通答疑、010，不能按措辞命中评分。

- 真实从Skill入口读取；逐条观察实际答复及工具，不用编造对话。主动读alpha当前P0、报告和材料身份；P0 v3与报告v2不对应，当前版本通过状态未知。报告不能证明评审、合并或规则确认。
- 仅询问实际阻碍判断的缺口。模拟补充只解决所述事项；如给出当前v3评审而无当前执行报告，仍不报当前已通过。复用已完成工作，不建议重走全部P0。
- 明确PRD→测试点发现、完整手写P0/录制→用例编写，已有测试点/QA→接续相应阶段。读取可访问实际适用规则，规则不可得时说清，虚构规则只为夹具结论。
- 不可读材料报告具体路径/原因；多个任务不按mtime/同名自动选。已能回答的部分照常答。至少一次真实补充后建议随证据更新。
- 普通问题直接回答，无强塞长流程。只读业务、原Skill、状态hash保持不变且工具无启动下游/发消息；hash相同不能独自证明无外部动作。
- 入口与metadata静态检查独立报告。宿主三个未调用场景实际不触发方可记该部分通过；actor手动读文件不能证明宿主隐式策略。
- 每项记录pass/fail/not-run与实际输入、答复、来源、工具、运行标识。没有行为证据一律not-run。
