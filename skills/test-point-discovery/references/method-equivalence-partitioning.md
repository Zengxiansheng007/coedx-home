# 等价类划分 / Equivalence Partitioning

出处：[ISTQB CTFL v4.0.1](https://istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf)，2024-09-15，§4.2.1，第39—40页；2026-11-07定向核读。以下为项目适配，非教材摘录。

适用：有依据认为同类数据按相同方式处理。不限于输入，可按输出、范围或离散类别分析。不适用：仅因外观相似就归类、尚不知道处理规则、想用一个代表值证明全部条件交互。

缺失信息：问处理依据、有效/无效定义、类别是否重叠或遗漏、唯一性作用范围、归一化与长度计数口径；不能自行把特殊字符定为非法。

应用步骤：从已知规则划类；核对同类同处理及类别边界；每类给代表检查与结果，未知类别标问题；多个输入的各自分类不等于所有组合已覆盖。无效类分别检查，避免一个拒绝遮住其他错误。

假设示例：编号全库唯一且必填已明确，空编号、已有编号、新编号有不同处理依据，可提出分别检查必填拒绝、重复拒绝、有效创建。大小写是否归一未知，就提问而非把A01/a01确定为同类。

误用提醒：不能凭“数字/汉字”外观划业务类别；不能把一个合法值代表全部格式、状态与权限；不能因方法生成候选就声称业务规则或执行通过。输出是可评审测试点，完整用例与执行由下游负责。
