# 边界值分析 / Boundary Value Analysis

出处：[ISTQB CTFL v4.0.1](https://istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf)，2024-09-15，§4.2.2，第40页；2026-11-07定向核读。项目适配与假设例不属于官方业务规则。

适用：有序等价类的分界、长度或数值范围。不适用：无序枚举、单位/精度/包含关系未知，或不存在可定义的最近邻。方法不能补造金额精度或时间容差。

缺失信息：问字段与比较阶段、单位、有效范围、开闭区间、最小可表示单位、字符/字节/其他长度口径、归一化、舍入模式和时点；连续量须先明确可接受粒度。

应用步骤：建立有依据的有序类别及界限，内部分析实际邻值。官方区分2值（边界及相邻类最近邻）与3值（边界及两侧邻值），按分析目标选择，勿将任何三数都叫3值边界。对外按[规则级编写](writing-review.md)表达范围、包含关系、计数或精度及越界结果，保留特殊业务边界，常规邻值数据交下游。缺失预期继续澄清，不计算覆盖率冒充执行。

假设示例：原额以元输入到分，x≥100减10已明确。内部可用99.99、100、100.01分析包含关系；若允许到厘，邻值按0.001取。待评审点表达“原额按元精确到分，满100减10，未满不减”，不逐项输出三组数据。名称限20字符时先核实计数口径；特殊字符若计数不同，保留该条件及跨越上限时的处理。

误用提醒：不机械±1；不把显示精度当计算精度；不忽略无效一侧或同一类内侧；检查了边界不代表所有类别/条件组合均验证。此处只发现必要边界点，完整用例数据与执行交下游。
