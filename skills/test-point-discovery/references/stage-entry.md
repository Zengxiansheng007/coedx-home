# 使用阶段与调用起点

每次调用先读取本参考，按实际消息含义区分新调用、明确指定阶段和当前流程答复。八个使用阶段统一如下。内部操作字母和开发工单号各自保留身份。

| 使用阶段 | 入口含义和必要材料 | 完成及下一步 |
| --- | --- | --- |
| 1 接收并核对资料 | 读取本轮PRD、调整说明、测试思路、已有稿及决定，核对版本、冲突、缺失、排除和目标，定位或建立唯一问答MD | 目标明确且材料足以分析，进入阶段2 |
| 2 澄清整体业务 | 核对业务目标、主要操作各自起点、业务变化、流程、上下游及未决依据 | 理解足以支持划分，进入阶段3 |
| 3 确认模块划分与梳理顺序 | 依据整体理解提出范围、组织方式、顺序和关联，实际archify表图及其展示记录 | 用户实际确认表图安排和关联范围，进入阶段4 |
| 4 深入澄清当前模块 | 读取已确认规划、当前模块范围、来源和唯一问答MD，澄清规则、条件、操作结果和终点 | 当前可问问题已处理，进入阶段5复核或继续澄清 |
| 5 问题处置与覆盖复核 | 回读原始资料、实际答复、漏答、部分回答、遗漏主题及依赖 | 问题均解决或获用户明确处置，覆盖复核完成后进入阶段6；有缺口回阶段4 |
| 6 集中编写待评审测试点 | 核对阶段3规划决定、阶段5问题处置及覆盖复核的实际记录，集中生成当前模块稿并自检 | 实际展示具体待评审稿、版本和范围，进入阶段7等待评审 |
| 7 人工评审、修改与模块收尾 | 读取实际展示稿、反馈和评审范围；修改重审，通过后更新唯一准确MD及版本，保存回读永久依据并安全收尾 | 本模块具体评审通过、准确MD及永久依据回读和适用收尾完成，按顺序进入下一模块阶段4 |
| 8 确定交接范围并交接 | 读取最新准确MD、实际具体评审、来源及未决依赖，整体核对术语、规则、衔接和终点，建议范围及用途 | 用户实际决定交接范围和用途，交付可恢复的准确MD及同文说明 |

## 入口判定

- **新调用未指定阶段。** 包括重新显式调用Skill且附已有稿，先实际进入阶段1，说明已读取的资料、版本、本轮目标与缺口。旧标题、阶段标记、文件存在或已评审稿只用于定位，不能单独证明可接续。
- **资料充分后的接续建议。** 阶段1核对当前目标、来源版本、规划及评审范围、准确稿、唯一问答MD的实际内容、未决与相关变化。只有可复用依据确实足以支持阶段X时，简述具体依据并问是否从阶段X继续。记录建议阶段和依据，等待用户实际回答。未答保持待决定，不执行该阶段工作。同意后按该阶段前提接续，拒绝后从阶段1按条件推进，已读取依据和有效决定继续保留。
- **用户明确指定阶段。** 如“从阶段6继续”，先实际读取表中必要材料、版本和相关记录。准确指出缺失规划确认、覆盖复核或具体评审的对象与影响，回到相应依赖阶段补齐，只暂停依赖缺口的工作。未知保持未知，明确部分可继续分析整理。明确指定无需再索取一次接续同意，真实问题、表图、具体评审与交接选择仍等待。
- **同一流程普通回复。** 自由回答、部分回答、具体稿反馈和约定范围内的“继续”承接当前阶段、模块、原问题及同一问答MD。先回读实际恢复位置，按原问题限定含义写入实际答复并回读，保留未答、历史和已有决定。普通回复无需重新启动阶段1；新一次显式调用且未指定阶段仍按第一项处理。

## 推进与恢复

条件满足后简述当前成果物及下一阶段任务并自动推进。阶段1材料充分时继续阶段2，不能仅宣布阶段名称就停止。实际提问、接续选择、表图确认、具体评审和交接决定处等待实际答复。

当前模块按4～7循环。阶段5复核后才在阶段6集中出稿，阶段7具体评审、准确MD保存回读及收尾后才深入下一模块。新疑问按4→5→6→7局部回流，保留现稿和无关有效决定。业务详细规则继续使用入口所链接的澄清、编写、评审和交接参考。

恢复时在唯一问答MD记当前使用阶段、模块、材料实际路径/版本、原问题及未决、下一动作和等待对象。问答MD承载过程，准确MD承载已具体评审测试点；初次没有准确稿时记录尚无。

## 入口例子

以下均为假设对话，实际运行保存真实消息与文件记录。

- 用户重新调用“使用 $test-point-discovery，这里是已有稿，请继续整理”。Agent先阶段1核对目标与版本，实际读取后发现M1已评审、M2有已确认规划和未决问答，说明这些依据并问“是否从阶段4继续M2”。未回复保持等待，同意后进入4，选择从头则从1按条件推进。
- 用户明确说“从阶段6继续”，回读发现Q02只答了计数、超限未答且未获处置，阶段5覆盖复核尚缺。Agent指出Q02及其影响，回阶段4承接原题，完成5后才集中编写。
- 当前对话用户答“中文英文都按一个字符”，Agent写回原Q02及同一问答MD，保留超限未答并继续问；这一普通答复延续当前阶段。

本参考规定Agent工作流。宿主或操作系统强制门、真实业务确认和客户端兼容性均需各自独立证据。
