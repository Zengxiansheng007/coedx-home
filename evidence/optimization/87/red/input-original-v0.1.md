# SIMULATION 标签小工具 PRD v0.1

全部资料及规划前提为本地技术模拟，不代表真实业务确认。

## P1 范围与接续前提

已确定先 M1 标签维护，再 M2 标签筛选。只梳理下列功能，流程与关联规划在本模拟中作为已确认接续前提，不重画图。允许先整理明确部分；进入下一模块仍按后续实际答复的继续范围处理。排除批量导入、权限、删除及完整测试用例。

## P2 M1 标签维护

标签分为工作、个人两类。新建表单两类都填写名称，必填，中英文各计1，最多12字，超限拒绝保存并保留输入。工作标签还须填用途，个人标签没有此字段。

保存成功产生一个标签 ID，列表出现该 ID 和已保存的名称、类别，重新打开详情看到同一内容。取消新建后回到列表，不新增记录。检查终点到列表与详情，不扩展到其他操作。

## P3 M1 待澄清规则

名称是否允许同类重复、跨类同名尚未决定。特殊符号和 emoji 的计数口径尚未决定，PRD 没有提供答案。工作用途的空值处理也未决定。各项实际答复可以分轮提供。

## P4 M2 标签筛选

按类别和名称筛选标签，选择后结果列出匹配 ID、名称、类别。名称采用精确还是包含匹配尚未决定。

筛选数据通过本地索引快照读取。当前包未附该快照，也没有其生成版本或包含的标签 ID，需资料提供方补交后才可核对新建标签进入索引的事实。不得凭当前 PRD 断言已收录。新建标签何时应可被筛选与索引更新条件，也尚待业务答复。
