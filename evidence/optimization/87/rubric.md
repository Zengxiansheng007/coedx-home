# #87 隔离语义评审与主持观察

此文件仅供 Root/独立评审，入口 actor 只收到普通 request、input、实际 Skill 路径和获授权输出目录。没有预填业务答案、对话或通过记录。

## 主持推进

按 actor 当轮实际问题发送短自然语言答复。可以只答同一问题的一个类别或一种行为，并明确其他部分未答；也可暂时省略另一个已问事项。后续实际补答。所有实际已知规则直接提供，不隐藏已有明确答案制造失败。

本材料中 P3 的重复范围、特殊符号计数、用途空值及 P4 的匹配、应可筛选时点确为未决定。业务答案由 Root 当轮决定并真实发送，不能由执行者填入。产品暂留必须有实际明确决定，只有“不知道”不够。

分阶段覆盖以下观察事件，可根据实际输出合并独立事件，不强迫固定轮数。

- M1 收到部分答复、漏答与新条件后，剩余内容仍实际追问。未具备前提的问题按依赖留存，前提明确后再问。
- 在尚有未处置疑问时只评审一块已经实际展示的明确内容，观察其他漏答、事实和依赖是否仍存在。不把规则答复或继续指令代作具体测试点评审。
- 在出现实际未决位置后暂停，恢复时只要求继续已保存的本次工作，观察实际读取过程与准确文档状态，不预先告知遗漏点。
- 明确决定一项规则后续问产品，再实际评审 M1 当前范围的具体稿。观察更新唯一 accurate.md、永久内容保存及回读、限定清理与回读。
- 根据真实继续决定进入 M2。P4 的本地快照当前未提供，主持需在后续实际发送或创建模拟资料后再给准确绝对路径。提交前不假定它存在。资料事实与“何时应该可筛选”业务决定保持分别记录。
- 在当前没有可问业务选择但本地快照事实仍未交付的时点，观察是否如实保持待查事实/依赖，不宣称本轮覆盖完成。
- M1 清理后，再由 M2 的实际新业务条件影响 M1 的一个规则或关联。主持只发送具体变化，观察执行者是否从永久依据新建受影响分支和问题，沿用其余有效决定。

事实材料须真实写入再提供路径，执行者实际读取。暂停、评审、答复、产品暂留与继续范围均由 Root 实际发送，最终评审只引用实际发生轮次。

## 独立语义核对

1. 来源去向包括未问主题、新条件、部分答复、漏答、事实缺口及依赖。临时区和永久问答位于同一过程 MD，稳定 B/Q 编号作用清楚，没有 JSON 业务副本。
2. 汇总回到原始 input 与答复历史。当前 frontier 空、点数多、部分评审通过均不能消除尚未处理项。事实不可查说明准确缺口与下一步，独立已明部分可按实际范围继续。
3. 收尾证据顺序可恢复。当前范围覆盖复核及具体测试点评审之后实际更新准确 MD，再将永久问题/实际答复/历史、来源、决定、产品影响、准确文档实际版本/路径及评审依据保存到临时区外并实际回读，然后才清理已收尾临时项。清理无需新增批准。
4. 清理前后比对永久内容和未处置行，已收尾临时项实际减少。其他模块、漏答/待查事实/等待前提保留。产品问题和影响从永久记录及准确 MD 恢复，不能只指向已删除 B 行。
5. 清理后变化仅重开受影响范围，新 B/Q 编号超过清理前实际最大值，旧问题与答复历史保留，未变条件和评审继续有效。修改按 #86 聚焦具体评审并更新原 accurate.md，其他内容保真。
6. 两类名称规则合并适用范围，工作用途真实差异保留；规则粒度和保存/取消终点沿用。只暂停依赖未知的部分，正文产品短引用保持未明确身份，避免回退 #82—86。
7. 问题记录与准确 MD 各有身份。永久引用为可定位实际绝对路径、版本/条目或实际问答位置，禁止模糊 source 简写。待评审、准确版和历史副本分别标记。

## 结果边界

逐项给出通过、失败或未验证及文件/轮次依据。静态核对、真实入口模拟、原生读取器、客户端和真实业务分别报告。本票不以旧轨迹或尚未执行的主持事件证明新版本通过。
