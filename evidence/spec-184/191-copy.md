规格 #184，工单 #191，AC-017。选择方式 1 的 P0 单次调用 HM-UP-006。三份稿件均由编写中入口生成，业务来源版本为 `ce126f8e238a52008195fabe2c5c84357fc4357bab9cdc7340a4449cccc061b1`。下表以 Markdown 文件的 SHA-256 标识每次送验的实际文件。

Markdown 检查使用 CommonMark 解析器提取本次调用唯一的代码块，在 Edge 渲染后一次选中全部内容，按 Ctrl+C、Ctrl+V 粘贴到本地输入框，直接解析并逐项核对同版数据。三份稿件都保留了空对象 `params`、`header` 的三组原有键值和数值型的 `transmissionType: 1`。核对页的预期数据另与同版单例逐字段比对。

v3 的第 47 行是输入名称，第 48 至 65 行是独立子项中的 JSON。Windows XMind 导入后，进入以左花括号开头的子主题，编辑主题文字，全选、复制一次并原样粘贴到输入框。AC-017 的客户端结果以这一次粘贴的内容为准。原始业务稿件、粘贴文本与逐次回执保存在本机。
