# 议题分流标签

| 技能中的角色 | GitHub 标签 | 何时使用 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 新议题等待维护者分流。 |
| `needs-info` | `needs-info` | 还需要报告者补充信息。 |
| `ready-for-agent` | `ready-for-agent` | 需求、范围和验收条件足以交给 Agent。 |
| `ready-for-human` | `ready-for-human` | 需要人工处理或实现。 |
| `wontfix` | `wontfix` | 维护者决定不予实施。 |
