# 单份记录契约

本文件提供扩展必需的持久化契约，不依赖上游自定义的 interview-record.md 或 requirements-delivery.md 是否存在。上游已有同义字段时复用，不建立第二份访谈记录或 JSON 副本。

沿用项目路径，缺省为 `docs/interviews/<主题>.md`；需求缺省为 `docs/requirements/<主题>.md`。已有同主题记录沿用原路径。会话材料保存于目标项目，不写入 Skill 或扩展安装目录。

## 永久内容

访谈记录应能定位以下信息，既有结构可映射这些字段：

- 目标、范围、原始输入与资料来源；文件资料包含可定位路径/章节及适用版本，聊天来源使用实际轮次或消息标识，不编造标识。恢复所需的原始要求摘要保留原意。
- 当前阶段、轮次、恢复位置和下一步；分支编号最大值在清理前记在这里，便于以后追加而不复用。
- 每个稳定 Q 编号：问题及选项、推荐与理由、具体例子、前提依赖、待更新位置、实际答复及来源、答复历史、当前归纳、未决项和影响。尚未答写“未回复”；改口追加历史与替代关系。
- 未曾提问而由资料或已有决定解决的事项、范围处置及理由也保存在最终决定区，引用资料或实际答复。永久结论的证据不能只指向稍后将删除的 B 行。
- 最终汇总版本、决定、范围调整、覆盖复核结论、待更新文档、汇总的实际用户确认。
- 需求文档实际路径、版本、问题/决定映射、当前版本的用户确认来源、清理状态；部分更新失败记录已完成与未完成内容。

保存用户原意和必要原话，归纳单列；凭据使用脱敏引用。实际答复为空时保持未回复。恢复时读取记录与相关来源、核对目标文档实际内容；前提变化只重开受影响分支，未变确认继续有效。缺少资料时保留事实阻塞，不凭上下文补造已确认状态。

## 临时区模板

将以下一个有界区放在同一访谈 Markdown 内。需要时追加行，状态与关闭依据遵循 extension.md。永久问答、确认和决定放在边界之外。

```markdown
<!-- grill-coverage:temporary:start -->
## 临时覆盖与分支表

| 分支 | 主题 | 来源 | 前置依赖 | 状态 | 问题或决定依据 | 下一步 |
| --- | --- | --- | --- | --- | --- | --- |
| B001 | 实际主题 | 原始输入/资料定位 | 无或 B/Q/事实项 | 未检查 | 无或 Q/永久决定定位 | 具体核查动作 |

<!-- grill-coverage:temporary:end -->
```

老记录无边界时先读取并明确识别工作表范围，再加边界；标记缺失或多对标记、永久内容误入临时区时，先修复结构与内容位置，不能按标题猜测并扩大删除范围。清理只删除这对边界及其内部内容。区外文本在清理操作前后保持不变；清理结果单独更新到永久状态字段。

## 版本确认的最小记录示例

以下仅为字段示例，实际值须来自当前访谈：

```markdown
## 文档审阅与清理
- 文档：实际路径，实际版本
- 汇总确认：实际来源；未确认则写未确认
- 当前版本确认：实际来源与用户答复；未确认则写未确认
- 分支编号最大值：本次实际使用值
- 清理状态：保留 / 待清理 / 清理中断（原因）/ 已回读核对完成
```
