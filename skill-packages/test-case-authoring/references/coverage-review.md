# 来源覆盖、范围与分级

首次提问、每轮答复后及汇总前使用本流程。复用 grill-with-docs coverage
1.0.0 的来源分支核对和 TPD 的逐轮覆盖设计；沿用 TCA 唯一问答 MD、
批次汇总和完整用例评审，不增加独立业务需求审批。

## 实际操作

1. 固定两种范围：完整批准 P0 验证范围及其原批准引用；本批拟评审用例
   和直接依赖。实际读相关来源与历史答复，逐项核对对象、条件、操作、
   分支和结果。评审副本、显示选择、局部合并不改变完整 P0 范围；核对
   报告仍把原批准 baseline 交给 check_extension，不从显示内容重建批准。
2. 每轮实际答复先保存回读，再更新已识别主题：稳定 B 编号、主题、来源
   位置、直接依赖、Q/实际决定依据、处置、下一步。新增来源或改口检查
   相关分支，保留无关决定；未检查、事实待查、待提问、等待前提分别保留。
   完成、延期、排除、不适用都写依据；延期仅决定处置，未知规则继续未知。
3. 当前问题均已处置时，**重新打开并读取**原始输入、补充资料、同一 MD
   全部相关答复历史和直接依赖。按原始条目核对去向，不能只遍历 Q/B 清单。
   对照对象、必要条件、异常/边界及终点；找回未登记主题后先查可查事实，
   再用 append_questions 登记新 Q，保存回读后实际完整提问。新问题使用
   超过当前最大编号的新编号；普通补答仍沿原 Q。读不到的来源写具体缺口
   与影响，事实阻塞不会因无可问问题消失。不要为了通过状态检查编造问题。
4. 范围外影响只登记来源、受影响对象、相关规则和扩展建议。用完整中文
   提问展示稳定 Q、可自定义选项、推荐、理由、主要代价/边界、标注假设的
   具体例子，等待用户实际选择纳入、延期或排除。分级建议同样提问：以
   当前影响、频率和损失说明建议 P0/P1/P2 与代价，不自行改变级别或范围。
   绑定触发该影响的本批用例，affected_checks 明确范围外对象。独立异常分支或
   范围外影响使用 disposition_scope: separate_impact，并用 scope_basis 说明
   与当前用例有效前提的区别；target_paths 必须为空。实际提问展示该区别，
   按用户原话记录延期或排除，未知业务预期继续未知。纳入范围后另问具体规则。
   当前用例必要规则默认 disposition_scope: case_rule；不因 target_paths 为空
   而免除阻塞。真实依赖继续通过 depends_on 连接；独立影响被延期时，其依赖
   问题仍等待，已明确的当前用例更新可继续。不得把未知必要规则标成独立影响。
5. 记录实际回读的每个来源位置及发现/去向、历史答复定位、直接依赖结论、
   当前范围及剩余限制。全部必要问题和来源主题已有依据或明确处置，且
   没有未处置事实/前提阻塞，才汇总；无新疑点沿用决定，不额外制造问卷。
   仅编写本批与直接依赖；范围外实际选择和延期影响完整保留在汇总。

## 同一 MD 的公开适配

`advance_record(path, 'append_questions', questions)` 校验新题、依赖图和完整
展示字段，保留旧题与答复，撤销旧汇总。它只追加问题，不写候选。

`advance_record(path, 'record_coverage', observation)` 保存实际复核；结构为：

- scope：batch_cases（本批全部用例 ID）、direct_dependencies（来源定位及
  依赖结论，可空）、p0_scope_ref（原完整批准引用；未到 P0 核对时写明阶段）。
- sources：实际回读的 ref 与 finding 列表；finding 写来源条目的具体去向。
- history_basis：本次实际回读的同一 MD 事件/答复范围；conclusion：覆盖范围、
  找回内容、处置和剩余限制。没有原始资料时明确当前输入来源与资料缺口。
- branches：id、topic、source、dependencies、status、basis、next_step。
  status 为 unchecked/fact_pending/question_pending/waiting/resolved/deferred/
  excluded/not_applicable。deferred/excluded 另需 question_id 引用同一 MD
  实际 deferred/formal 答复；Agent 核对原话确实批准对应主题及范围。

每轮更新同一组 B，旧项保留并更新状态。程序拒绝删除已识别 B、无实际答复
的延期/排除；记录后答复或新增题会使复核过期。汇总保留覆盖和延期信息。
直接依赖相关的实际资料要读原文，不能把填好此结构称为复核。

## 证据能力边界

程序只校验结构、来源定位存在、问题身份、声明依赖、答复引用及修订版本；
它不理解原始资料、不保证找全主题、不证明读取发生、不认证业务事实。
兼容旧纯 API 的调用不会自动产生覆盖证明。现场 Skill 必须完成上述实际
回读流程再汇总；独立实际分轮模拟验证遗漏发现、范围选择和分级行为。
结构回归、语义模拟、真实业务执行分别报告；未知预期不靠字段或关键词补齐。
